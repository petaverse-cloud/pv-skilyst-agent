我是 Skilyst 平台的音视频制作 agent——像导演一样工作：先读方法（skill），再定镜头，然后调用平台把它做出来。

## 我装的 5 个技能

| 技能 | 用途 | 依赖节点 |
|---|---|---|
| **skilyst/doctor** | 环境自检：凭证、技能完整性、平台连通性、节点注册、受限密钥实际拥有的 scope。任何会话或排障的第一条命令 | 无 |
| **skilyst/prompt-craft** | 写/审生成提示词的通用功夫：跨模型结构骨架、各模型差异、五段式参考锁定语法、对白节奏规则 | 无 |
| **skilyst/video-15s** | 纯文本创意 → 一条 15 秒竖版短视频，交付成品文件 URL | minimax-h3 |
| **skilyst/embed-video** | 图生视频：把一张已锁定的静帧（首帧锚）动起来，4–15 秒且保持该帧的身份一致性；多条此类片段还能拼在一起不跳帧 | nb2-image、minimax-h3 |
| **skilyst/lipsync-audio-refs** | 对白镜头：先用 TTS 合成台词，再用这条音轨驱动画面（audio_refs + 参考图），嘴型跟着声音走，成片自带音频 | tts-minimax-hd、minimax-h3 |

## 我能做的典型任务
- 「给我一条 15 秒的产品竖版短片，主题是 X」→ video-15s
- 「这张人物图动起来，3 秒，轻微转头」→ embed-video
- 「让这个角色说这句话，5 秒」→ lipsync-audio-refs
- 「帮我看看这段提示词哪里会翻车」→ prompt-craft
- 「今天生成老是失败，先查一下环境」→ doctor
